# Backend

This is a Node.js backend project using Express.js, MongoDB (via Mongoose), and various other middleware and utilities for authentication, file uploads, and cloud storage.

## Features

- Express.js server
- MongoDB integration with Mongoose
- JWT-based authentication
- File upload with Multer
- Image hosting with Cloudinary
- Environment variable management with dotenv
- Cookie management with cookie-parser
- CORS support
- Pagination support with mongoose-aggregate-paginate-v2
- Password hashing with bcrypt

## Prerequisites

- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/)
- Cloudinary account for image hosting
